# Journal study data

This directory contains the executed evidence for the IEEE paper.

## Layout

- `raw/` — per-trial CSV and JSONL logs, plus one summary JSON per experiment.
  The directory is git-ignored so that a run can write logs without making the
  tree dirty. The release archive is `raw_logs.tar.gz`.
- `raw/archive/` — earlier runs kept for audit: the pre-provenance P0-REACH run
  (`83909cb`), the earlier P0-ESTOP run (`99966bd`), and an E-STOP run aborted
  after six trials when the tree was made dirty during the run.
- `figures/` — figures regenerated by `scripts/build_numbers.py`.
- `ledger.csv` — one row per paper macro: value, unit, sample size, interval,
  source file, and source commit.

Every CSV row carries `exp_id`, `commit`, `short_commit`, `dirty`, `started_at`,
and `finished_at`. No reported number is typed into the manuscript.

## Rebuild

```bash
python3 scripts/build_numbers.py
```

The script aborts if a required summary is missing or if the rows of an
experiment do not carry exactly one non-empty commit. It writes
`publications/ieee_tro_submission/numbers.tex`, `data/journal/ledger.csv`, and
the five paper figures.

## Archive contents

`raw_logs.tar.gz` contains the evaluation CSVs, summaries, the main JSONL
sidecars, and the archived CSVs/summaries. JSONL sidecars for the archived and
smoke runs are omitted to keep the archive small; their CSVs and summaries are
included. The archive is a byte copy of the logs used by `build_numbers.py`;
the commit stamps are inside the files, not inferred from the archive.
