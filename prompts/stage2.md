File: arm_control/arm_control/force_estimator_node.py

  Estimates contact force WITHOUT a force sensor.
  Based on servo position error and current draw.
  
  Method:
    expected_pos[i] = commanded_joint_angle[i]
    actual_pos[i]   = /joint_states position[i]
    position_error  = expected_pos - actual_pos
    
    # Under load, servo lags behind command
    # Lag magnitude correlates with torque
    
    estimated_torque[i] = K_spring * position_error[i]
    # K_spring calibrated per servo type:
    #   MG995: K = 0.5 N·m/rad (approximate from stall spec)
    #   SG90:  K = 0.15 N·m/rad
    
    # Gripper: estimate grasp force from gripper position error
    gripper_estimated_force = K_gripper * gripper_position_error
    
  Publishes:
    /force/joint_torques  (Float64MultiArray: 5 joints)
    /force/gripper_force  (Float64: estimated grasp force N)
    
  Used for:
    - Grasp slip detection: sudden drop in gripper force → slip
    - Object detection: unexpected torque → unexpected contact
    
  Note: APPROXIMATE. Calibrate K values by testing with known weights.

File: arm_control/arm_control/kinematic_calibration_node.py

  Continuously monitors and corrects kinematic model drift.
  
  Process (runs every 100 tasks or on demand):
    1. Move arm to 5 calibration poses (known joint configs)
    2. At each pose: detect AprilTag → get visual end-effector position
    3. Compare FK(joint_angles) vs visual measurement
    4. Error = visual - FK prediction
    5. Fit calibration offsets: minimize sum of squared errors
       Using scipy.optimize.minimize (Nelder-Mead)
    6. Store offsets in arm_ik/config/calibration_offsets.yaml
    7. IK node reads these offsets and applies them
    
  Compensates for:
    - Servo wear (offset at neutral)
    - 3D print tolerances (slight link length error)
    - Assembly variation (joint axis misalignment)
    
  Service /aria/kinematic_calibration: trigger calibration
  Service /aria/kinematic_calibration/status: get drift estimate
